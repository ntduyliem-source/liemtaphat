# Result image resources

`result-image.js` composes the immutable `ContentExport.Parts` snapshot. It does not read formula source or DOM text to choose a candidate. The preview element supplies only its width. `renderer.js` supplies MathJax outlines and baseline metrics. A formula alone keeps its natural size; a paragraph keeps explicit line breaks and wraps words to the captured content width.

`inter-outline.json` contains 1,032 glyph outlines and advances from the three local Inter 400 subsets in `Locus.DesignSystem/wwwroot/fonts`. It is generated by `python tools/design-system/export-font.py` with fontTools 4.63.0; its header records input SHA-256 values. The original Inter OFL license is beside those source fonts. See [fontTools SVGPathPen](https://github.com/fonttools/fonttools/blob/main/Lib/fontTools/pens/svgPathPen.py) and [variable-font instancing](https://fonttools.readthedocs.io/en/latest/varLib/instancer.html).

Latin/Vietnamese text and formulas remain vectors. Graphemes outside this font (including emoji and complex scripts) are shaped by the browser, rendered at 4X, and embedded as PNG glyphs inside the SVG. They therefore need the generator's fonts only when exporting, never on the receiving machine. The fallback is deliberately raster, not a promise that every script/emoji has a vector outline or that an OS has every Unicode glyph. The CT4 receipt records the actual Vietnamese/emoji samples verified.

No screenshot or foreignObject is used. References are internal glyph IDs or embedded PNG data. PNG 2X/4X uses this same SVG, with a 24-million-pixel and 32,767-pixel-per-edge limit checked before canvas allocation. It never reduces the requested scale silently. Existing transparent/white-background document settings are honored independently of UI theme.
